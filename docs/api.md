# REST API

Base URL: the server's address, e.g. `http://localhost:8080`. All JSON errors look like
`{"error": "<code>", "message": "<human text>", ...details}`.

**Device authentication** (booth endpoints): `Authorization: Bearer <DEVICE_API_KEY>`.
Public endpoints need no account; session IDs are 128-bit random values, so they cannot be guessed.

## Discovery

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/health` | – | `{ok, time, emailEnabled, designs}`; touches the database. Use for monitoring. |
| GET | `/api/config` | optional | `{publicBaseUrl, galleryUrlTemplate, sessionIdPattern, emailEnabled, maxUploadBytes, authenticated}`. `authenticated` tells the booth whether its key is valid. |
| GET | `/api/designs?photoCount=3` | – | Installed designs (optionally only those for a photo count): `{designs: [{id, name, description, version, width, height, photoCount, previewUrl}]}` |
| GET | `/api/designs/:id/preview` | – | The design's `preview.png` (or a rendered placeholder). |

## Booth (device) endpoints

All are **idempotent**: repeating a request after a timeout is always safe.

### `POST /api/sessions`
```json
{ "id": "Q2xhdWRlIHdhcyBoZXJlIQ", "eventId": "summer-party", "eventName": "Summer Party",
  "photoCount": 3, "capturedAt": "2026-06-01T18:30:00Z", "deviceName": "Booth iPad", "designId": "classic-white" }
```
* `id`: 22–64 base64url characters generated by the booth (≥128 random bits).
* `eventId`: lowercase slug; the event is created on first use (gallery disabled by default).
* `photoCount`: 1–12. `capturedAt`, `deviceName`, `designId`, `eventName` optional.

`201` created / `200` already existed (same body) → session status (see below). `409` if the ID exists with a
different event or photo count.

### `POST /api/sessions/:id/photos?index=0&sha256=<hex>`
Body: the original JPEG bytes (`Content-Type: image/jpeg`). `index` is 0-based (`X-Photo-Index` header also accepted);
`sha256` is optional but recommended (`X-Photo-SHA256` header also accepted).

| Status | Meaning |
|---|---|
| 201 | stored: `{index, sha256, bytes, width, height, duplicate: false}` |
| 200 | identical photo already stored (`duplicate: true`) |
| 409 | a *different* photo already exists at this index (never overwritten), or the session is complete |
| 413 | larger than `MAX_UPLOAD_MB` |
| 415 | not a readable JPEG |
| 422 | `checksum_mismatch`: body does not match `sha256` (corrupted transfer — retry) |
| 400 | bad index / dimensions over `MAX_IMAGE_DIMENSION` |

Originals are stored byte-for-byte (never re-encoded) as `originals/01.jpg`, `02.jpg`, …

### `POST /api/sessions/:id/complete`
Body (optional): `{"sha256": ["<photo 0>", "<photo 1>", ...]}`. Marks the session viewable once every photo is
present. `409` with `{missing: [indexes]}` or `{mismatched: [indexes]}` otherwise. Pending emails are sent afterwards.

### `GET /api/sessions/:id/status`
```json
{ "id": "...", "eventId": "summer-party", "status": "uploading|complete", "photoCount": 3,
  "photos": [{"index": 0, "sha256": "...", "bytes": 10485760}], "missing": [1, 2],
  "galleryUrl": "https://photos.example.com/s/..." }
```
The booth compares the checksums with its local copies before marking a session as synchronized.

### `POST /api/sessions/:id/email`
Body `{"email": "guest@example.com"}`. Queues the fixed "your photos are ready" email with the gallery link.
Accepted while the session is still uploading; delivered once it is complete. `202` queued, `200` same address
already queued, `400 invalid_email`, `404` unknown session, `429` per-session (`EMAIL_MAX_PER_SESSION`) or hourly
(`EMAIL_MAX_PER_HOUR`) limit, `503 email_disabled` when SMTP is not configured.

## Public endpoints (guests)

Unknown and still-uploading sessions are indistinguishable from outside.

| Method | Path | Description |
|---|---|---|
| GET | `/api/sessions/:id` | `202 {status: "processing"}` until complete; then `{id, url, event{name, accentColor}, capturedAt, photos[{index, width, height, thumbUrl, mediumUrl, originalUrl, downloadUrl}], designs[{id, name, photoCount, thumbnailUrl, previewUrl, downloadUrl}], defaultDesign, downloadAllUrl}` |
| GET | `/api/sessions/:id/photos/:index` | Original JPEG (byte-identical). `?size=thumb` (480 px) or `?size=medium` (1600 px) for resized copies; `?download=1` adds `Content-Disposition: attachment`. |
| GET | `/api/sessions/:id/strip?design=<id>` | Full-resolution strip for a compatible design (default design if omitted). `&size=preview` for a ≤1600 px preview; `&download=1` to download. Rendered on demand and cached. |
| GET | `/api/sessions/:id/download` | ZIP of all originals, streamed on demand. |
| GET | `/api/events/:eventId` | Event gallery header `{id, name, accentColor, sessionCount}` — only if the event gallery is enabled and accessible. |
| GET | `/api/events/:eventId/sessions?offset=0&limit=24` | `{sessions: [{id, url, thumbUrl, photoCount, capturedAt}], nextOffset}` |

## Pages

| Path | Page |
|---|---|
| `/s/:sessionId` | Session gallery (strip preview + design picker, photos, fullscreen viewer, downloads, native share). Always works, regardless of the event gallery setting. |
| `/gallery/:eventId` | Event gallery (disabled → 404; password mode → password form). |
| `/admin/` | Admin UI (password = `ADMIN_PASSWORD`). |

## Admin API

Authenticate with the `/admin/login` cookie or HTTP Basic auth (any user name, password = `ADMIN_PASSWORD`).
Mutations require `Content-Type: application/json`.

| Method | Path | Body / notes |
|---|---|---|
| GET | `/api/admin/overview` | events with counts, designs, design problems |
| POST | `/api/admin/events` | `{id, name}` |
| PATCH | `/api/admin/events/:id` | any of `{name, galleryMode: "disabled"|"public"|"password", galleryPassword, accentColor, defaultDesign}` |
| DELETE | `/api/admin/events/:id` | `{"confirm": "<event id>"}` — deletes all sessions and photos |
| GET | `/api/admin/events/:id/sessions?status=&limit=&offset=` | sessions with upload status and masked email status |
| DELETE | `/api/admin/sessions/:id` | deletes the session and its files |
| POST | `/api/admin/emails/retry` | requeue failed emails |
| POST | `/api/admin/designs/reload` | rescan `DESIGNS_DIR` |

Example:
```bash
curl -u :$ADMIN_PASSWORD -X PATCH -H 'Content-Type: application/json' \
  -d '{"galleryMode":"password","galleryPassword":"party2026"}' \
  http://localhost:8080/api/admin/events/summer-party
```
